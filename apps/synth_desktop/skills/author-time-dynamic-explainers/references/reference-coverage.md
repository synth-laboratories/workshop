# Reference reconstruction coverage

Internal reconstruction studies were rendered and inspected at 1100 × 760.
They are validation artifacts, not production task assets.

The next reconstruction pass should target the post-pipeline primary set in
this order: sharded backups, S3 consistency, B-tree insertion, model-size
comparison, then sharding overview. Read-repair and older chalkboard studies are
no longer part of the acceptance bar.

## Sharding overview

Covered:

- near-black canvas;
- small application row and a single query-router spine;
- dense, evenly aligned database matrix;
- dashed quiet control connectors;
- one warm moving request particle and active route;
- complexity revealed by increasing repeated units.

Required skill rules: dark infrastructure family, repeated infrastructure
topology, dense data plane with sparse control plane, closely matched pacing.

## Massively parallel backups

Covered:

- identical shard-aligned lanes;
- stable production database objects;
- temporary restore and WAL objects in warm outline;
- lifecycle advancing in lockstep;
- shared freeze-time barrier and final backup destination;
- temporary compute disappearing after completion.

Required skill rules: parallel lifecycle lanes, semantic color, stable object
identity, synchronization barrier, bounded completion.

## Read repair

Covered:

- six stable numbered nodes in a sparse ring;
- values written immediately beside their owning nodes;
- proxy and application servers retained as separate boundary objects;
- stale replicas in muted red;
- a single active read particle followed by green repair paths;
- repaired values changing in place rather than creating replacement nodes.

Required skill rules: routed regional system, visible causal paths, semantic
state color, update-in-place, and one dominant transformation per beat.

## Gaps found and corrected

- The earlier typography rule incorrectly preferred sans-serif throughout; the
  dark diagram family now calls for restrained hand-drawn labels.
- The earlier palette guidance was too abstract; the skill now defines stable,
  active, healthy, and stale roles for the dark family.
- The skill now explicitly permits close reconstruction only as an internal
  audit, while keeping production compositions original.
