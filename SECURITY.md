# Security policy

Do not open a public issue for a suspected vulnerability or include secrets in
a report. Contact the Synth Laboratories maintainers privately through the
security-reporting channel listed on the organization profile. Include the
affected Workshop version, impact, reproduction steps, and any proposed fix.

Workshop v0.10 supports macOS 14 and newer on Apple Silicon. Only the latest
published stable release receives security fixes. Source builds and official
downloads are ad-hoc signed, not Apple-notarized. Verify release assets against
their published checksums and provenance before permitting first launch.
