Date drafted: 2026-09-09

Current state: **local candidate certified; nothing pushed, published, deployed, production-signed, or notarized**

This is the operator checklist for publishing v0.10 across Workshop, its OSS dependency family, backend, frontend, evals, and release infrastructure. Every checked item must carry an evidence value: commit SHA, PR URL, workflow URL, deployment ID, migration revision, package version, artifact digest, or probe output. A bare checkbox is not release evidence.

## Release strategy and invariants

- [ ] Name one release DRI and one rollback DRI; record names in the release packet.
- [ ] Record explicit authorization for pushes, package publication, staging deployment, production deployment, production signing/notarization, and any paid verification.
- [ ] Open one v0.10 release packet in the team release system and link this checklist.
- [ ] Freeze a UTC release window and a no-conflicting-writers window for every repository being promoted.
- [ ] Preserve the promotion order: feature/release branch → `dev` → `staging` → `main` for cloud repositories.
- [ ] Preserve Workshop's repository-specific policy: candidate → `dev` → `main`, then fast-forward `dev` to the released `main` tip.
- [ ] Never force-push `dev`, `staging`, or `main`; use reviewed PRs or an explicitly approved fast-forward.
- [ ] Deploy only committed, pushed SHAs. Never package or deploy a dirty worktree.
- [ ] Do not use macOS Keychain-backed Workshop secrets. Release credentials must come from already-authorized CI secrets, project-local environment files, or the approved secrets proxy.
- [ ] Do not run provider-backed training as a deployment smoke unless it is separately budgeted. Before a paid run, state one aggregate maximum charge and expected actual cost.
- [ ] Treat Railway deployment `SUCCESS` plus SHA/health parity as the gate; an HTTP response from an older deployment is not success.
- [ ] Stop the train at the first unexplained new failure, migration divergence, missing artifact, incorrect pin, or mismatched deployed SHA.
