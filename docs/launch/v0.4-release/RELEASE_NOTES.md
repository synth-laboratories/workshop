# Synth Desktop v0.4.0

v0.4 adds bounded Banking77 and Craftax GEPA workflows, transcript-first Craftax trace review, fail-closed container/eval capability checks, and locally correlated diagnostics.

Live visual replay now uses declared transports and durable lane-local cursors. Generation-speed history is immutable, completed-turn elapsed time follows durable turn boundaries, and review capture has a dedicated window identity. Reconnects preserve stream identities and evidence, open panes reconcile committed revisions, and absent timing or token metrics are no longer rendered as zero.

This cut is an ad-hoc-signed, unnotarized friends release for macOS 14 or later on Apple silicon. Updates remain manual.
