## CUA gate — installed candidate only

Run on a **clean tree** install (`npm run desktop:install` refuses dirty trees). Isolate data roots (`./scripts/desktop-instance.sh cua candidate` or `SYNTH_DESKTOP_DATA_ROOT`). Independent tester; not the implementer. Record SHA + app version in the receipt.

### Permissions

1. Fresh chat. Permission chip is not “Full” by default.
2. Open the menu. **Full system access** is distinct from **Workspace access** and says unrestricted filesystem and network.
3. Selecting Full system access changes the chip to Full. Unrestricted chats start at the user home directory, not a synthetic workspace.

### Approval UX

1. With Ask / untrusted, prompt a shell command that needs approval.
2. The approval card pins **above** Working… with Reject, Approve once, and Always allow for this session.
3. Stop / cancel the turn. The card and Working… both disappear. No leftover Approve once.

### Live visuals (replay or cheap live, not ten paid seeds)

1. Open Craftax, Harbor, and dig.bench visuals from the library (fixture or a sealed receipt spool).
2. Missing reward/usage render as missing (`—` / not emitted / pending), never `0.00` or `$0.00`.
3. `stream.subscribed` is not shown as evidence.
4. dig.bench has no `<img>` / PNG frame.
5. Two open visuals do not import each other’s observations.

### Tool-loop (Laguna S or a model that emits `shell` / malformed `visual_manage`)

Pass when all of these hold. Today this is still a promotion blocker if any fail:

1. Unsupported `shell` maps onto the supported command-execution tool or fails closed with a model-readable error.
2. MCP discovery lists only implemented Visuals tools. `resources/list` / `resources/read` are absent.
3. Malformed nested `visual_manage.arguments` is rejected with a corrective error, not retried forever.
4. Repeated identical protocol failures stop or escalate. Token/cost risk is visible while looping.
