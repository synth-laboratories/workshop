## Scheduled v0.7 work

All work previously classified as `post-v0.6 / version TBD` is now scheduled
for v0.7:

- broader chart interactions: sorting, filtering, linked selection,
  annotations, and persistent view-state polish;
- experiment DAG visualization;
- hosted CISPO launchability, subject to a valid canary promotion gate;
- local CISPO uplift and product surface, subject to full proof;
- additional models, datasets, and algorithms beyond the bounded v0.6 paths;
- local public-cookbook catalog and download UX plus broader cookbook turnover;
- rich catalog tags, rename/purge, and advanced checkpoint-library polish;
- OHCO and GELO hosted optimizer support;
- consent-safe analytics or growth instrumentation;
- audience-selector polish while preserving server-authoritative authorization.

Existing v0.7 optimizer-workbench planning remains part of this scope.

## Release truth

- The currently published stable application and download remain v0.6.0 until
  a verified v0.7 artifact is built and released.
- Creating the integration branches does not claim that the scheduled features
  are implemented.
- Apple notarization is not scheduled by this scope decision. The v0.6 release
  remains explicitly ad-hoc signed and unnotarized, per user direction.
