## The GUI pass

Completed 2026-08-21 against the signed isolated CUA build. The pass found and
fixed two launch-only defects: a zombie sidecar was mistaken for a live process
after SIGKILL (`8b06988b`), and native provider preparation overwrote the
selected policy with the base model (`d31d1e6e`). Daemon evidence during the
re-run showed `attachedPolicy` change from `synth/Laguna-XS-2.1-ft` to
`poolside/Laguna-XS-2.1-NVFP4-mlx` in the same conversation, then back to the
finetune in a second conversation. All three turns completed normally.

`npm run dev` in `apps/synth_desktop` launches an isolated v0.7 instance.

1. **Settings → Models → On-device** — a “Laguna XS 2.1 finetune” card below
   the base model, 6.6 MB, base revision `841778bda563`, Download button.
2. **Download** — preparing → downloading → verifying, then “Installed”. A
   verification failure must surface as an error, never a silent success.
3. **Composer model picker** — under Local: base and the finetune, each with a
   tok/s figure or an em dash. A percentage delta appears only when the daemon
   marks it resolvable; blank is correct on a busy machine.
4. **Select the finetune, send a prompt** — normal reply; first turn pays a
   cold load.
5. **Switch back to base mid-conversation** — no reload stall beyond a ~20 ms
   swap. This case used to reload 20 GB.
6. **Second chat on the other policy** — each conversation keeps its own. The
   old build could not do this.

**The published adapter is neutral**: rank 8, `lora_b` all zeros,
mathematically the identity. It cannot change a single token. If the finetune
appears to do nothing, that is the expected result. Use
`~/.synth-desktop/laguna/test-adapters/probe-r8` to see a policy actually
change output.

## Traps already hit

- **Comparing output text proves nothing** at default temperature. An earlier
  test reported the neutral adapter as changing output, which is impossible.
  Assert on `attachedPolicy` and throughput sign instead: an attached LoRA does
  strictly more arithmetic per token and cannot be faster than its base.
- **A neutral adapter cannot prove attachment.** That is what `probe-r8` is for.
- **End-to-end throughput measures the scheduler** — it swung 37% between
  identical runs under load. Use p10 of per-token latency, and never quote a
  figure without its measurement floor.
- **Tree digests must match byte for byte** between `local_lora::digest_directory`
  and the publisher; a cross-language test pins this.
- **Adding a Tauri command** means bumping the count in `contract/specta.rs` and
  regenerating `protocol.ts`.
- **A Tauri build fails on missing bundle resources** before compiling anything:
  run `scripts/stage-packaged-cookbooks.sh` and stub the Computer Use helper path.
