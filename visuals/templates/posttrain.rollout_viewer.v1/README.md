# posttrain.rollout_viewer.v1

Standard **trajectory / rollout** viewer for PostTrainBench-style inspection.

## Features

- Timeline scrubber with play/pause
- Step list with action + reward
- Cumulative reward sparkline
- Observation text panel

## Slots

| Slot | Accepts |
| --- | --- |
| `trajectory` | fixture, local_cas, trace_v5 |
